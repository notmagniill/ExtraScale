<h1>Contributing</h1>
First, fork the repository! Download the <code>ExtraScale.rbxm</code> and put it inside any place in Roblox Studio, then implement any feature you would like in the plugin and create a pull request for me to check your implemented features!
<h1>Bug Reporting</h1>
Go to the Issues tab and create a new issue, mark it as a bug, then write what is wrong and provide some evidence and how to recreate it (if not we will ignore your issue). I will try our best to resolve your issue as soon as possible!
<h1>Suggestions</h1>
Same as Bug Reporting but a little bit different, instead of marking it as a bug, mark it as a enhancement, then write what you think should be implemented and explain a little bit on how it should work!
